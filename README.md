# Guild Manager React

This project is a World of Warcraft-inspired guild management app built with React.

You recruit heroes with different races, classes, roles, and professions, send them on missions, level them up, and improve their gear through loot rewards. The current gameplay is tuned for a level 20 cap for testing, with the code structured to expand progression further (for example, toward level 60).
